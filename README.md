# 🚀 DevTrack Dashboard

A responsive developer productivity dashboard built from scratch using **HTML, CSS, and JavaScript**.

DevTrack is the first project in my journey toward becoming an **AI Full-Stack Developer**. The project focuses on building a clean dashboard interface while learning the fundamentals of frontend development and Git/GitHub.

---

## 📌 Overview

DevTrack provides a dashboard-style interface for monitoring developer activities such as projects, tasks, skills, and productivity.

The project was built as a hands-on learning project, with a focus on understanding how HTML, CSS, JavaScript, CSS Grid, and Flexbox work together to create a responsive web interface.

---

## ✨ Features

- 📊 Dashboard overview
- 📁 Project statistics
- 📦 Category tracking
- 👥 User/customer statistics
- 🔔 Alert section
- 📱 Responsive layout
- 🎨 Modern dashboard UI
- 🧭 Sidebar navigation
- 🔎 Search interface
- 🌙 Dashboard-style dark theme
- 🔣 Material Icons
